# Puddle – Online Marketplace

Puddle is an open-source Django web application that creates a local peer-to-peer marketplace. 
Users can post items they want to sell, browse listings from their community, filter by category, 
and communicate directly with other users through an integrated messaging system.

## Key Features
- **User Authentication**: Secure signup, login, and session management
- **Item Listings**: Create, edit, and delete product listings with image uploads
- **Category Browsing**: Filter items by predefined categories
- **Real-time Messaging**: Built-in inbox system for buyer-seller communication
- **User Dashboard**: Manage your own listings and track sales
- **Responsive Design**: Mobile-friendly UI built with Tailwind CSS
- **SQLite Database**: Lightweight, zero-configuration persistence
